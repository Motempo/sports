# Country flags

SVGs in this folder are the 4×3 set from [flag-icons](https://github.com/lipis/flag-icons) (MIT). They are committed so the sports pages can draw real flags without a CDN and without emoji glyphs.

Copyright (c) 2013 Panayiotis Lipiridis. See `LICENSE` in this folder.

Do not hotlink `flagcdn.com` or another flag host. `lib/country-flag.ts` only returns a path under `/flags/` when that file is listed in `data/flag-codes.json`.
